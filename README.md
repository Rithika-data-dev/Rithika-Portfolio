# S. Rithika - Portfolio

A single-page static portfolio (HTML, CSS and a little JavaScript). No build step.

## Run locally
Open `index.html` in a browser.

## Deploy on Render
1. Push this folder to a GitHub repository.
2. On render.com choose New > Static Site and connect the repository.
3. Branch: `main`. Build Command: leave empty. Publish Directory: `.`
4. Click Create Static Site.
